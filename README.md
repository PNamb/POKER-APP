# Texas Hold'em Poker App ♤ ♡ ♧ ♢
This is an [Expo](https://expo.dev) project

## The app is broken up into three parts
1. The Game Engine
  ```All game engine files are written in javascript. They handle dealing cards, player actions, bot actions and behavior, and evaluating hands.```
2. The UI
  ```Components are written in React, while hooks and contexts are written in javascript. They handle displaying buttons, screens, and persistent settings.```

3. Networking
  ```All networking files are written in javascript. They handle hosting a room, joining a room, disconnecting from a room, etc.```

## The Screens
The app is seperated into the following screens:
1. Home Screen
2. Join Screen
3. Lobby Screen
4. Game Screen
5. Settings Screen
6. Profile Screen
7. Guide Screen

### Home Screen
Contains routing buttons for hosting and joining, as well as the settings, profile, and guide
